# Formation IA CJEPE-BENIN

Ce dépôt contient la version numérique de la formation IA de l’Institut de Formation Professionnelle CJEPE-BENIN.

## Contenu
- Page d’accueil de présentation de la formation
- Page de cours structurée par modules
- Intégration de la formation 15 séances IA
- Ressources et parcours IA complets

## Structure
- site/index.html : page d’accueil du site
- site/formation.html : page de cours
- site/assets/ : styles et scripts
- Formation 15 séances IA/ : plateforme pédagogique complémentaire

## Déploiement
Le site est conçu pour être publié via GitHub Pages à partir du dossier site.
